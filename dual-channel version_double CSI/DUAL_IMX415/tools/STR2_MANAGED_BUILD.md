# STR2 Managed TD Build

Open `dual_imx415_gray_demo.al` through TD's Open Project menu.
Enter these commands individually in the GUI Tcl Console:

```tcl
reset_runs syn_1 -f
launch_runs syn_1 -step opt_gate
```

TD's GUI `source` filter rejects these project-management commands inside a
script. Do not wrap them in `source`. Do not use `close_project` or
`open_project` in the GUI console: reopen through the project menu instead.

Verify the fresh Read Design, Optimize RTL and Optimize Gate run records and
`dual_imx415_gray_demo_Runs/syn_1/run.log`. Verify source registration against
the `.prj` generated by that run. Gate mapping does not establish routed
timing closure or a successful board test.
