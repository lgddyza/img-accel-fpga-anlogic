# RK 时域去闪前后摄像画面对比（2026-10-03）

## 采集与配对

FPGA 保持模式 3（高斯预处理 + 直方图均衡），摄像头和场景不变。在 RK 上临时暂停 HDMI 播放，用 `/dev/video73` 一次抓取 20 张连续、完整的 1920×1080 GREY8 帧，共 41,472,000 字节。再用板上实际部署的 `rktemporalgray` GStreamer 插件重放处理这 20 帧，得到同样大小的输出。按帧序号一一配对；处理后的图不是另一时刻重新拍摄的画面。

`before_after_comparison.png` 按之前的三列版式显示第 9～11 帧：左侧为 FPGA 均衡后、RK 去闪前的画面，中间为同帧 RK 去闪后画面，右侧为两者的对数直方图（青色为处理前、橙色为处理后）。`continuous/` 保存第 9～16 帧的一对一预览数据；预览按水平、垂直各取每 3 个像素中的 1 个，分辨率 640×360。图上标注的是预览均值。

`mean_intensity_20_frames.png` 显示 20 帧的时间序列。均值在完整 1920×1080 帧上按固定位置每 64 个像素采 1 个计算，因此与预览均值略有差别。原始统计及逐帧指标见 `comparison_stats.json`。

## 结果

| 指标 | 处理前 | 处理后 |
| --- | ---: | ---: |
| 第 5～20 帧相邻均值平均跳变（0～255 灰度级） | 29.581 | 0.638 |
| 第 9～16 帧预览的平均 5%～95% 灰度跨度 | 226.75 | 226.50 |
| 第 9～16 帧预览的平均邻域梯度 | 13.116 | 12.913 |
| 第 9～16 帧预览中纯白像素平均占比 | 0.06% | 0.54% |

相邻帧整体亮度跳变降低 **97.84%**。同一场景的明暗帧在处理后接近一致，同时 5%～95% 灰度跨度基本保持，图中的纹理、边界位置没有空间模糊。8 组配对图的像素相关系数为 0.9945～0.9999。

代价是原本较暗的帧被抬亮后，少量高光达到 255：纯白像素占比从平均 0.06% 增至 0.54%，暗帧最高约 1.15%。此外，滤镜从首帧启动时，20 帧内处理后均值由约 138 缓慢向 131 收敛，说明启动阶段仍有轻微渐变。对比赛展示而言，目前去闪收益明显；若后续追求高光细节，可限制 LUT 顶端增益并再复测。

这组数据验证的是**板上同一 RK 插件对连续真实摄像帧的效果**，不是对 HDMI 物理屏幕的相机翻拍。采集完成后 HDMI 实时播放已恢复，日志显示 sink 约 60.0 FPS；短时离线重放不作为实时帧率测试。屏幕实际闪烁已由用户观察确认明显消失。原始完整帧位于 RK 的 `/run/temporal_raw20.gray` 与 `/run/temporal_filtered20.gray`，重启后会消失；本目录留存缩略帧和统计。
