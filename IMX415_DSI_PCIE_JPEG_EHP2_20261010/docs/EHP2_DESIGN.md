# 当前EHP2结构与控制接口

## 数据路径

```text
IMX415 RAW10 -> ISP -> 灰度 -> 共享3×3窗口
                               ├─中心灰度──────────────────────┐
                               ├─Gaussian──────────────────────┤
                               ├─Sobel引导增强─────────────────┤ -> SOF锁存选择
                               └─膨胀3 -> 腐蚀3 -> 黑帽响应    │         │
                                  -> 四方向line5滤波            │         v
                                  -> gain1暗化增强──────────────┘ 共享CLAHE/直通
                                                                     │
                                            1080p按8行交错分三路JPEG -> PCIe -> RK
```

原灰度窗口能供高斯、Sobel和黑帽首级共用。第二级腐蚀作用于膨胀结果，不能用原灰度窗口代替。四方向响应滤波也需要独立缓存。

所有分支流水并行，最终只选一路。增强后可选CLAHE，未实现Sobel和黑帽同时增强，也未实现自动场景分类选模式。

黑帽：`C=erode3(dilate3(I))`，`B=max(C-I,0)`，分别对B作水平/垂直/两个对角线长度5开运算并取最大D，输出 `max(I-D,0)`，gain1。Sobel沿用T1/gain0.5。高斯是3×3 `[1,2,1]`外积/16。

CLAHE是一套2×2分块、clip factor2、前帧LUT、双线性插值和1/4时域IIR实现。切换增强输入后存在LUT过渡，应等待若干帧再做稳定图像比较。

## 模式

| 模式 | 名称 | 顺序 |
| --- | --- | --- |
| 0 | gray | 灰度 |
| 1 | gauss | 灰度→高斯 |
| 2 | clahe | 灰度→CLAHE |
| 3 | gauss-clahe | 灰度→高斯→CLAHE，复位默认 |
| 4 | sobel | 灰度→Sobel |
| 5 | blackhat | 灰度→黑帽K3/gain1/line5 |
| 6 | sobel-clahe | 灰度→Sobel→CLAHE |
| 7 | blackhat-clahe | 灰度→黑帽→CLAHE |

## PCIe控制寄存器

| 偏移 | 用途 |
| --- | --- |
| 0xAC | EHP2算法标识0x45485032 |
| 0x104 | 支持模式位图0xff |
| 0xA4 | 请求模式0..7，非法写入退回0 |
| 0x100 | 输入SOF锁存的实际生效模式 |
| 0xA8 bit0 | 预处理缓存溢出、对齐或帧重叠故障 |
| 0xB8 | JPEG质量请求QF |
| 0xF8 | JPEG质量生效反馈，bit7有效、低7位QF |
| 0xF0 | JPEG帧率选择；RK在停止接收时设60FPS |

模式更新按帧生效，反馈不表示下游已消费完上一模式的所有帧。各分支须在下一帧前排空，不能在行中切换输出。

DDR/MIPI/PCIe所需 `.ipc`、生成HDL、约束、PCIe配置数据和DSI指令ROM初始化文件均保留。厂商文件头内的历史生成路径是注释，保留原始字节；它们不是当前工程的外部源引用。
